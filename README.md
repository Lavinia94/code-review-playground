# code-review-playground

Test repository for an AI-powered code review agent (EPAM AI Engineer Program, Module 4 – MCP).

Pull requests in this repository contain intentionally flawed code. They are used to verify that the agent:

- retrieves pull request data through the GitHub MCP server
- reviews only the files changed in the pull request
- posts inline review comments on the correct lines
- submits an overall review summary

⚠️ The code in the pull requests is deliberately poor quality. Do not use it as a reference.
